Connect Supabase (free)

Keeps every record safe in the cloud and lets your iPhone add SMS silently. Setup steps are in the README on GitHub.

iPhone SMS capture

With cloud sync (silent, recommended)
  1. Shortcuts → Automation → + → Message.
  2. Message Contains Bal (or pick your bank senders). Choose Run Immediately.
  3. Add Get Contents of URL. URL: https://YOUR-PROJECT.supabase.co/rest/v1/inbox
  4. Method POST. Header apikey = your key. Only if the key starts with eyJ, also add Authorization = Bearer + key.
  5. Request Body JSON: key raw, value Shortcut Input.

Nothing opens. The SMS lands in your inbox and is added the next time you open the app.

Without cloud (opens the app)
  1. Same automation trigger as above.
  2. Add URL Encode on Shortcut Input.
  3. Add Open URL: followed by the URL Encoded Text.

Use the Safari bookmark, not a Home Screen icon. On iPhone they keep separate data.
